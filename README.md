## Что в файлах

- [`train.py`](train.py) содержит модель, обучение на двух GPU и валидацию. Это основной файл, на который стоит смотреть
- В [`training_and_val.py`](training_and_val.py) модель вынесена в [`model.py`](model.py)
- [`train_profile.py`](train_profile.py) нужен для профилирования, [`shapes.py`](shapes.py) помогал проверять формы тензоров
- Подробности и замеры есть в [`report.pdf`](report.pdf). `time.txt` и `memory.txt` содержат таблицы профилирования (не уверена, что там находятся последние данные)

## Как запустить

На Kaggle выбрать T4 ×2, кладём `train.py` в `/kaggle/working` и запускаем из ячейки:

```python
!cd /kaggle/working && torchrun --standalone --nproc-per-node=2 train.py
```

## Что получилось

В последнем запуске `train.py` пик составил **9109.43 объектов/с**, средняя скорость за пять эпох — **7710.57 объектов/с**, MAE на валидации — **0.12434**. По сравнению с исходными 13.27 объектов/с пиковая скорость выросла примерно в **686 раз**
